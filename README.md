# miniwebisteadmin-f

Digital Business Card & Mini Website Builder Admin Application.

## Environment Setup

Create a `.env` file in the root directory or copy `.env.example`:

```bash
cp .env.example .env
```

Set the backend server URL:

```env
VITE_SERVER_URL=https://f5z16x7l-3500.inc1.devtunnels.ms/api/v1/
```

## Getting Started

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build production bundle:

```bash
npm run build
```
